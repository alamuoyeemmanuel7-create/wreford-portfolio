# Wreford portfolio (React + Vite)

    npm install
    npm run dev      # local preview
    npm run build    # production build in dist/

1. Put photos in `public/images/`: `logo.png`, `hero.jpg`, `about.jpg`, `brands-1.jpg` to `brands-4.jpg`, `weddings-1.jpg` to `weddings-4.jpg`, `events-1.jpg` to `events-4.jpg`.
2. Edit `src/config.js`: WhatsApp number, social links, and video links for projects.
